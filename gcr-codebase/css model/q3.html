Gradient Background Demo

Linear Gradient

This section's background transitions smoothly in a straight line from one color to another, using background: linear-gradient(...). It also uses background-attachment: fixed; so the gradient stays put while the page scrolls, creating a subtle parallax-like effect.

Radial Gradient

This section's background radiates outward from a central point using background: radial-gradient(...), producing a circular color transition instead of a straight one.
