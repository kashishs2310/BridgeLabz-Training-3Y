Core Principles of Responsive Design

Fluid Layouts

Layouts sized with relative units so they resize smoothly with the viewport.

.container { width: 90%; }

Flexible Media

Images and media that scale within their container instead of overflowing it.

img { max-width: 100%; }

Breakpoints

Specific viewport widths where the layout changes to fit the screen better.

@media (max-width: 600px) { }
