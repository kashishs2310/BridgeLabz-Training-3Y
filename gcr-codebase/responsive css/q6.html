Responsive CSS Cheat Sheet

Filters

CSS functions like blur(), grayscale(), and sepia() applied via the filter property to images or elements.

Media Queries

Rules such as @media (max-width: 600px) that apply styles conditionally based on viewport size.

Responsive Design

An approach that makes layouts adapt fluidly to different screen sizes using flexible grids and units.

Typography

Using relative units (rem, vw) and clamp() to let font sizes scale smoothly with the viewport.
