Box-Sizing Comparison

width: 250px
padding: 30px

box-sizing: content-box (the default) — the 30px padding is added on top of the 250px width, so this box actually renders wider than 250px.

width: 250px
padding: 30px

box-sizing: border-box — the 30px padding is included inside the 250px width, so this box's total rendered width stays exactly 250px.
